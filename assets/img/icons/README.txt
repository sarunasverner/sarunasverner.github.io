Official icons for the footer links go here. Save them as

  inspire.svg   scholar.svg   orcid.svg   github.svg   kicp.svg

(.png or .webp also work; square images, at least 64 x 64 px). Then run `cd source && python3 build.py`.
Any icon that is missing keeps the site's generic line icon. Use the files each service provides for linking to a
profile (for ORCID, the iD icon from its brand guidelines).
