From field evolution to spectra

Numerical solver

The repository contains sphaleron_solve.c, a standalone C implementation of the coupled radial field equations underlying the sphaleron calculation.

Analysis notebook

The Mathematica notebook Reading the Spectra.nb accompanies the solver and supports inspection of the output spectra.

Documentation and scientific context

The repository README provides an overview and build guidance. The associated papers set out the assumptions, equations and interpretation of the numerical results.

Questions about the calculation?

For scientific questions, write to verner@uchicago.edu. For source files and documentation, visit GitHub.
