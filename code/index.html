Code behind the calculations

Public code from my research in theoretical particle physics.

sphaleron-decay

A numerical solver for the radial SU(2)-Higgs field equations that govern electroweak sphaleron dynamics.

  • C solver
  • Mathematica notebook
  • Companion to two Physical Review D papers
Open the repository on GitHub

What the repository contains

Numerical solver

sphaleron_solve.c is a standalone C program that solves the coupled radial field equations behind the sphaleron calculation.

Analysis notebook

The Mathematica notebook Reading the Spectra.nb reads the solver’s output, so you can inspect the resulting spectra.

Documentation and scientific context

The README explains what the code does and how to build it. The two papers give the assumptions, the equations, and how to interpret the results.

Questions about the calculation?

Write to verner@uchicago.edu with questions about the physics. The source files and documentation are on GitHub.
